# Paper Quest texture provenance

`paper_base.png`, `kraft_base.png`, `notebook_grid.png`, and `tape_mask.png` were supplied in the user-provided `paper-quest-figma-generator.zip` design handoff for this repository.

They are decorative implementation textures only. Runtime text, controls, state, icons, and interaction remain native Godot UI. High Contrast mode suppresses these texture layers.
