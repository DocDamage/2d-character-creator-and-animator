## Overview

This document maps every normative requirement in the master plan to implementation tasks, verification tasks, source files, tests, and evidence bundles.

## Requirement Statuses

| Code | Meaning |
|------|---------|
| `PLANNED` | Requirement exists but no implementation has begun |
| `IN_PROGRESS` | Active implementation in a thread |
| `IMPLEMENTED_UNVERIFIED` | Implementation claims completion; independent verification pending |
| `VERIFIED` | Independent verification confirmed behavior |
| `BLOCKED` | Cannot proceed due to dependency or discovered issue |
| `REJECTED` | Approved rejection with rationale |
| `DEFERRED_WITH_APPROVAL` | Approved deferral with target milestone |
