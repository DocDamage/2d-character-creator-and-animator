# Manual Acceptance Scenario

1. In Saved Poses, bind a rig, capture/apply/mirror/blend/add additive poses,
   inspect the selected thumbnail, and save a sketch suggestion without
   modifying the rig first.
2. Bind a source pose/profile and target profile/rig to Retarget Preview,
   preview the mapped compensation result, process a batch, then apply a
   correction layer.
3. Confirm missing roles, wrong rigs, empty sketches, bad maps, invalid lengths,
   and incompatible blends return diagnostics without silent mutation.
