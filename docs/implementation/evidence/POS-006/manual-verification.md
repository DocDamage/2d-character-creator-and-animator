# Manual Verification Scenario

1. Capture or select a named pose in **Saved Poses**.
2. Confirm a 128×96 image appears under **Selected Pose Thumbnail** and shows
   an origin marker with spokes/markers for saved bone positions.
3. Select another pose with different local positions and verify the preview
   changes while the source pose data remains untouched.
4. Clear the library or deselect its list and confirm the panel presents the
   empty-preview guidance instead of stale imagery.
