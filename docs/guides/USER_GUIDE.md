# User Guide

Start in the workspace matching the task: Create for imported character layers,
Rig for poses and retargeting, Animate for layered composition, Weapon &
Equipment for grips/solvers, and Preview & Export for Batch Export. Use
F6/Shift+F6 to move between docks, F10 for the menu, and Ctrl+Shift+P for the
command palette.

Character creation is import-only. Create a project, choose a canvas and slot
template, then import a PNG/WebP/JPEG file or an artwork folder. Folder and
drag-and-drop imports map names such as `head`, `body`, `hair`, and `hands` to
their layer slots. No character artwork is generated by the application.

Select an assembled layer to move it, scale, rotate, change its pivot, opacity,
or tint, and to reorder, hide, lock, solo, duplicate, replace, or delete it.
The history line names the next document-level undo action, so the same Undo and
Redo stack follows you through Create, Rig, Animate, and Weapon workspaces.

Autosaves appear in the Project hub as an elapsed time such as “Autosaved 30
seconds ago.” After an unclean exit, Paper Quest offers the newest recovery
automatically. Quality & Recovery lists dated recovery candidates with a small
project preview before you restore one. Bundled samples are read-only: use Save
As before modifying them.

The Project hub lets you rename, duplicate, archive, reveal, or repair a recent
project location. Project duplicates bring their imported artwork along. Use the
Asset Browser and Create’s repair action to find duplicate or missing files.
