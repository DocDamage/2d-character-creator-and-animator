# User Guide

Start in the workspace matching the task: Character Creator for modular parts,
Animation Studio for layered composition, Weapon & Equipment for grips/solvers,
and Preview & Export for Batch Export. Use F6/Shift+F6 to move between docks,
F10 for the menu, and Ctrl+Shift+P for the command palette.

Open Quality & Recovery before overwriting a damaged project. It lists usable
backups/autosaves and runs the same scale, accessibility, and release-safety
checks used by the project fixtures.
