# Asset Authoring Guide

Register parts and slots, bind a body type, then use Character Creator to
browse compatible parts, lock choices, apply palettes, randomize, save presets,
and restore sessions. Use the Facing Grid dock for directional assets and the
Media Authoring dock for references that must stay excluded from exports.

For deformable assets, validate bone weights before export. The Deformable Mesh
sample demonstrates the intended weighted runtime mapping.
