# Weapon Authoring Guide

Define a weapon, its interaction family, grips, action points, and pose profile.
Use Weapon Authoring Wizard coverage to address missing bindings, then choose a
drive mode and preview/solve both hands. The 20 Weapon sample is the regression
fixture for supported equipment workflows.

In Animation Composition, keep weapon overlays separate from masked body layers
so they can be previewed and exported independently.
